also, id like to know how you see the task at hand. i see it as a spoken language understanding (SLU) na task instead of closed vocabulary keyword spotting (KWS). {
"audio": "path/to/wav",
"text": "turn on the lights",
"intent": "control_lights",
"slot": "on",
}

Hello!

@MarkMacalalad , tinry ko i-match 'yung data schema na sinend mo sa metadata ng SLURP dataset. Found the following matches (attached).

Note lang na:
1. sentences = unique voice prompt (e.g. "wake me up at ten" → alarm_set)

2. recordings = actual audio files per sentence, usually several (different speakers/mic setups) - e.g. one sentence has 9 separate recordings

3. matched intents = how many of SLURP's own intents got mapped to one of your labels. Mostly 1-to-1; LIGHT_OFF = 2 (legacy duplicate, e.g. "turn off the light" vs. "turn off lamp"), BRIGHTNESS = 4 (dim up/down x 2 naming schemes, e.g. "dim the lights" vs. "the lights are too bright")

4. Hindi ko pa na-download lahat ng audio files, based lang talaga to sa labels/counts sa metadata ng slurp dataset. Though nagstream ako ng mga 3 samples per label, and parang legit naman haha
